NER-LRMS FRONTEND PROTOTYPE
===========================

This is a static, frontend-only demonstration website for the proposed
AI-Based Early Warning and Landslide Risk Monitoring System for Northeast India.

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html (or right-click -> Open with -> Chrome / Edge).
4. Internet is only needed if you want the optional Google Font to load; the site
   otherwise uses system font fallbacks.

PAGES INCLUDED
- Dashboard
- Risk Map & Analysis
- Live Monitoring
- Alerts & Warnings
- Field Reports
- Data & Sensors
- ML Model
- Reports & Analytics
- Manage Users
- Settings

INTERACTIONS
- Sidebar navigation between pages
- Search box, state/district filters and map layer toggles
- Alert tabs and approve/review demo actions
- Field report modal and local form submission feedback
- Sensor feed sample updates
- CSV export for field reports and summary
- Responsive desktop/tablet/mobile layout

IMPORTANT
All counts, readings, locations, map overlays, timestamps, alerts and metrics are
illustrative dummy data for presentation only. No backend, database, weather API,
GIS service, IoT sensor, authentication or trained ML model is connected.
Do not represent the mock data as live measurements or validated predictions.

For the presentation, describe this as a frontend prototype / proposed interface.

VISUAL THEME UPDATE
The dashboard theme has been aligned to the supplied PPT references: dark navy
mountain sidebar, pale blue-white canvas, larger bold typography, soft cards,
and satellite-style map panels cropped from the user's own reference screenshots.
